# DevSentinel visual assets

These SVGs are the source files for the project architecture visuals:

- `architecture-end-to-end.svg` — trust boundaries, durable workflow, execution,
  AI, and delivery.
- `repair-journey.svg` — the normal repair path plus clarification, regression,
  and safe-stop branches.
- `security-evidence-gates.svg` — the six application-enforced gates and the
  credential flow.

They are hand-authored vector diagrams, so GitHub renders them sharply at any
size and future contributors can edit labels or layout without recreating a
bitmap. Each SVG includes an accessible title and description.

The product uses the exact public avatar configured for GitHub App ID `4855052`
from `https://avatars.githubusercontent.com/in/4855052`. The dashboard keeps a
small local fallback mark so its header still has a usable identity offline.
